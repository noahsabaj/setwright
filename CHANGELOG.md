# Changelog

## 0.2.0 — 2026-09-13

- Install Setwright as a Windows app with a Start Menu shortcut and uninstaller.
- Check for signed updates, read release notes in the app, and opt into automatic updates.
- Open papers in Write mode, with direct LaTeX editing in Source mode.
- Navigate included files and headings while preserving per-file drafts and editor state.
- Save named versions and restore earlier paper content.
- Use responsive navigation drawers and resizable Editor/PDF panes, including at 200% zoom.
- Render equations with locally bundled math fonts.
- Preserve rejected edits and block closing while changes or encoding conversions are pending.

PDF compilation requires a separately delivered, verified compiler runtime and is unavailable in this build. This is an early authoring release; cross-platform release certification remains in progress.

## 0.1.0

- Initial development version of the local-first, source-preserving LaTeX editor.
